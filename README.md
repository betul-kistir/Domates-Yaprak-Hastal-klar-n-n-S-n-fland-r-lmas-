# Domates-Yaprak-Hastaliklarinin Siniflandirilmasi
# Domates Yaprak Hastalıklarının Sınıflandırılması: Laboratuvar ve Gerçek Ortam Veri Setleri Üzerine Karşılaştırmalı Bir Çalışma

Uygulamalı Yapay Zeka Dersi Dönem Projesi

## Proje Amacı
Bu projenin temel amacı; kontrollü laboratuvar ortamında (PlantVillage) eğitilen derin öğrenme modellerinin, karmaşık arka planlı ve doğal ışık koşullarındaki gerçek tarla ortamı (PlantDoc) verilerinde yaşadığı performans düşüşünü (genelleme problemini) analiz etmek ve karşılaştırmaktır.

## Kullanılacak Veri Setleri
1. PlantVillage Dataset (Laboratuvar Ortamı):Sağlıklı yapraklar dahil 10 farklı sınıfı barındıran RGB görüntüleri.
2. PlantDoc Dataset (Gerçek Ortam):Gerçek tarla koşullarındaki dış test veri seti.
